# 🎓 Smart Student Analytics System

## 📌 Project Overview

The **Smart Student Analytics System** is a web-based application developed to manage and analyze student academic performance.

The system allows users to store student information, marks, and attendance, and automatically generates useful academic insights. It helps identify top-performing students, average-performing students, and students who may be at risk due to low marks or attendance.

The project reduces manual calculations and provides an easy-to-understand analytical view of student performance through tables, statistics, rankings, and charts.

---

## ✨ Key Features

- 🔐 User login and authentication
- 👨‍🎓 Add and manage student records
- ✏️ Edit and delete student information
- 📊 Automatic calculation of total marks
- 📈 Student performance analysis
- 🏆 Top 5 student ranking
- 🥇 Topper identification
- ⚠️ At-risk student identification
- 📅 Attendance analysis
- 🔍 Student search and filtering
- 📊 Bar charts and pie charts for visualization
- 💡 Performance-based recommendations
- 📋 Complete student performance report
- 🤝 Tie handling in student rankings
- 📌 Summary statistics such as average, highest, and lowest marks
